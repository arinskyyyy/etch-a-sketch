# Etch-a-Sketch

A browser-based sketching application built with vanilla JavaScript, HTML, and CSS. This project allows users to draw on a digital canvas by hovering over a grid, mimicking the classic Etch-a-Sketch toy with a modern, colorful twist.

## Features

* **Interactive Drawing:** Hover over the canvas grid to leave a trail of randomized RGB colors.
* **Dynamic Grid Resizing:** Users can clear the canvas and generate a new grid of any size between 1x1 and 100x100 via the "Grid Reset" button.
* **Retro UI/UX:** Styled with a nostalgic pixel art aesthetic, including a custom font (Pixelify Sans) and custom pixelated mouse cursors.
* **Responsive Layout:** Centered, neatly contained user interface using CSS Flexbox.

## Technologies Used

* **HTML5:** Semantic document structure.
* **CSS3:** Flexbox for layout management, DOM styling, custom fonts (Google Fonts), and external cursor mapping.
* **JavaScript (ES6+):** DOM manipulation, event listeners (`mouseover`, `click`), and dynamic element generation.

## How to Run Locally

Since this is a vanilla front-end project, no build tools or package managers are required.

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/arinskyyyy/etch-a-sketch.git
   ```
2. Navigate into the project directory:
   ```bash
   cd etch-a-sketch
   ```
3. Open the `index.html` file in your preferred web browser.
